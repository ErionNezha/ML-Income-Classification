# 💰 Klasifikimi i të Ardhurave (ML)

Notebook-u origjinal trajnon **Logistic Regression** mbi datasetin *Adult Census Income* (~48,000 rreshta, `income_evaluation.csv`) për të parashikuar nëse një person fiton mbi 50K$/vit. Demoja në browser është **simulim edukativ** me pesha të thjeshtuara: plotëson moshën, arsimin, profesionin, orët e punës dhe fitimin nga kapitali, dhe merr 'parashikimin' me probabilitet e faktorë ndikues.

## Si ta hapësh

Hap `index.html` në browser — tab-i **Live Demo** tregon demon funksionale, tab-i **Kodi Burim** tregon të gjithë kodin.

Ose hap direkt `demo/index.html` për demon.

## Struktura

- `index.html` — faqe showcase (Live Demo + Kodi Burim)
- `demo/` — demo/index.html (simulim), original/Untitled.ipynb, original/income_evaluation.csv
- `original/` — burimi origjinal i paprekur
